# Family-38 PRDM9-A motif analysis

`analyze_family38.py` scans near-full-length Family-38 homologs for the
degenerate human PRDM9-A-compatible recognition motif. The script accepts
explicit genome, annotation, reference, output, and minimap2 paths; run it in
the supplied Conda environment with `python analyze_family38.py --help`.

The compact result tables include the motif-retention percentages reported in
the supplementary table. Genome assemblies are referenced by accession and are
not redistributed here.
